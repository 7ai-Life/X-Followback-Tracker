# 隐私说明

适用版本：v1.1.0。更新日期：2026-09-30。

X Followback Tracker 在浏览器本地分析 X 页面中已经渲染的关注卡片，并添加视觉标记。

## 读取与保存

- 读取当前页面路径、个人主页导航链接、关注按钮和回关标识，以确定是否应添加标记。
- 通过浏览器 `storage.local` 保存标记开关和用户自愿填写的用户名。
- 不保存关注列表历史，不读取密码、Cookie 或 Token。

## 网络与第三方

- 扩展不调用 X 的关系 API，不将读取的信息发送到服务器，不包含分析或广告 SDK。
- 点击作者或项目链接会打开相应网站，由该网站处理普通访问请求。

## 权限用途

- `storage`：保存本地设置。
- X / Twitter HTTPS 页面内容脚本：在匹配的网站中运行页面识别逻辑；实际标记仅作用于自己的正在关注页面。
- 不请求全站访问、Cookie、浏览历史或自动下载权限。

## 清除数据与联系

在浏览器扩展管理页移除扩展，可清除该扩展的本地设置。问题请通过 [GitHub Issues](https://github.com/7ai-Life/X-Followback-Tracker/issues) 或 [作者 X](https://x.com/7ai_Life) 反馈，勿公开敏感信息。
