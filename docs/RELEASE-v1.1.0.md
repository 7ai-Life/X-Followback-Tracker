# X Followback Tracker v1.1.0

在自己的 X「正在关注 / Following」列表中，用浅红背景和「未回关」标签标出未显示回关标识的账号。

## 下载与安装

下载本页 Assets 中的 **X-Followback-Tracker-v1.1.0.zip**，解压后在 Chrome / Edge 扩展管理页开启「开发者模式」，点击「加载已解压的扩展程序」，选择其中的 **extension** 文件夹。

[完整安装教程](https://github.com/7ai-Life/X-Followback-Tracker/blob/main/docs/INSTALL.md)

安装后刷新 X，进入自己的「正在关注」列表即可。无需 Node.js 或 API Key。

## 包含功能

- 未回关高亮与滚动后的自动识别。
- 标记开关和当前已渲染账号计数。
- 自动识别账号，支持手填用户名。
- 独立 Logo、浏览器图标与品牌弹窗。
- 作者入口：[七乂 · 7AI Life](https://x.com/7ai_Life)。

数据在本地处理，不上传，不自动关注或取关。判断依据页面「关注了你 / Follows you」标识的有无，页面变化或加载延迟可能影响结果；计数不代表全部关注关系。

7 项回归测试通过；作者提供了真实 X 页面使用反馈和截图。
